## 图表4：Compaction详细过程

```
┌────────────────────────────────────────────────────────────┐
│              Compaction 触发条件监测                        │

│                                                             │

                │                      │

    ┌───────────────────┐    ┌───────────────────┐
    │ 1. 选择L0所有文件  │    │ 1. 选择Ln中文件   │
    │ 2. 找L1重叠文件   │    │ 2. 找Ln+1重叠文件 │
    └─────────┬─────────┘    └─────────┬─────────┘

                       │
                       ▼

        │            │                     │
        │            ▼                     │
```
